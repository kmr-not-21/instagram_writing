# カレンダー投稿 執筆ルール

インスタグラムアカウント：https://www.instagram.com/hana.moja_/
店のコンセプト：「花とグリーン、どちらも主役級。特別なかけあわせ。」

---

## 1. 全体構成（3〜4段落 + フッター + ハッシュタグ）

カレンダー投稿は営業日案内を兼ねた月次投稿。花の魅力を伝えつつ、実用的な情報を自然に織り込む。

### 第1段落：季節の花の紹介（軽め）

- **冒頭1文は時候の挨拶＝生活体感から入る。** 「店先に〜が並びはじめました」のような店視点ではなく、「日毎に暑さが増し、夏の空気が近くまで感じられるようになりました」のように**気温・空気・季節の体感**を起点にする。店内・商品描写は2文目以降。
- その月に入荷している旬の花・グリーンを**2〜3種類**さらりと紹介する。
- 季節感を伝える描写を入れるが、通常投稿ほど深掘りしない。
- 「〜が楽しくなってくる時期です」のような柔らかい語り口。

### 第2段落：営業日・休業日のお知らせ

- **不定期休業日**を具体的な日付と曜日で明記する。
- 簡潔に、丁寧な言い回しで（「〜となりますので、ご来店の際はご確認くださいませ」）。

### 第3段落：今月の見どころ + 来店誘導

- 今月の店頭に並ぶ商品や作品の見どころを軽く紹介する。
- **ギフト需要**や**ご自宅用**の提案を自然に盛り込む。
- 🌱 のような絵文字を**1つ**使ってよい。
- **`(*^^*)`** で文末を締める（毎回必須）。

### フッター（固定テンプレート）

通常投稿と同じフッターを使用する。

```
---------

『花とグリーン、どちらも主役級。特別なかけあわせ。』
花屋Moja

所在地：神奈川県藤沢市下土棚260-9
営業時間：9:00～18:00(水曜のみ13:00まで・日曜定休)

※不定期のお休みや時間変更については、カレンダーの投稿をご確認くださいませ。

---------
```

### ハッシュタグ

- **5個**とする。
- 必ず含めるもの：`#藤沢花屋` `#湘南花屋`
- **地域名タグを3〜4枠に拡張する。** `#藤沢花屋` `#湘南花屋` に加えて、藤沢市内・隣接エリアの地名タグ（例：`#湘南台花屋` `#長後花屋` など）を1〜2枠追加する。地元検索流入を意識した運用で、花材タグ・季節タグは1〜2枠に絞る。
- 季節やその月の特徴に合わせて選ぶ。

## 2. 文体・トーンのルール

- 通常投稿と同じ **です・ます調** を基本とする。
- 通常投稿に比べて**軽やかで簡潔**なトーン。詩的な深掘りは控えめに。
- 体言止めはキャッチコピー的な要素には使ってよいが、全体的には情報伝達を優先する。
- 親しみやすく、月の始まりのワクワク感を演出する。
- **修飾語は最小限に**：一つの名詞句に形容語を重ねない（×「深い赤の整った花姿のバラ」／○「整った花姿の赤バラ」）。比喩・装飾語は効果的なポイントに絞り、全体に散らさない。
- **語り手の主観介入を避ける**：「私たちは思います」「〜と思います」のような介入表現は冗長。直接断定する（×「決まった色や形はないと、私たちは思います」／○「決まった色や形はありません」）。
- **来店誘導は共同行為のトーンを優先**：「ぜひMojaで〜してください」のような改まった敬語より、「Mojaで〜を一緒につくりましょう」のように店主と顧客が並走する親しみあるトーンを選ぶ。
- **句点ごとに改行する**：インスタの可読性を優先し、長い文を改行なしで連続させない。一文ごとに改行する。
- **「ですます」を3文以上連続させない**：段落内で「〜です」「〜ます」「〜あります」のような述語が3回以上続くとリズムが平板になる。体言止めを織り混ぜて緩急をつける。
- **動詞の擬人化・装飾化を避ける**：「ふっくら重なる」「抱え咲く」のような擬人的・装飾的動詞より、「ふっくらした」「丸い」のような口語的な形容の方が読み流しやすい。装飾は名詞句に絞り、動詞はシンプルに。
- **漢語より和語を優先する**：堅い漢語は親しみある和語に置き換える（×「想いを託す花」／○「想いを乗せた花」）。Mojaの「店主が語りかけるトーン」に整合する。
- **主語の明示と助詞による連結明確化**：「は」で主語を明示すると読みやすさが上がる（×「実はこちらの花束、〜」／○「実はこちらの花束は、〜」）。複合語感を避けるため助詞「の」で連結する（×「ゴールデンウィーク帰省」／○「ゴールデンウィークの帰省」）。

## 3. コンテンツの注意事項

- **過去に使った文章のそのまま引用・再利用は禁止。**
- **直近のカレンダー投稿とメッセージ・切り口を重複させない。** 上記「過去引用禁止」は文章レベルの規約。その上位概念として、過去のカレンダー投稿が既に伝えた**主張・切り口・提案ポイント**（例：「春のワクワク」「ご自宅にも彩りを」「ギフトにもご自宅にも」など）の重複も避ける。前月・前々月のカレンダー投稿のメッセージ要点を初稿前に内部で整理し、既出主張は別の切り口に置き換えてから書き始める。
- 営業日情報は正確に記載すること（必ず確認を求める）。
- 季節性は現在日時を参照し、旬の花や行事と自然に結びつける。
- **投稿文面のファイル形式は `.txt`（プレーンテキスト）とする。** `.md`（マークダウン）では `(*^^*)` などの記号がマークダウン記法として解釈され、意図しない表示になるため。
- **写真がある場合は構成を正確に把握すること。** 思い込みで内容を決めつけず、不明点は確認する。
- **AIが写真から推測した花材の質感・形状は断定しない。** ステップ1の確認が取れるまでは描写を確定しないこと。
- **テーマのキーワードや表現は事前に検討すること。** 新しい概念や造語を使う場合は、一般的な理解のされ方・誤解の可能性・代替表現を検討し、ユーザーに確認を取ってから執筆に入る。
- **花材の入荷時期に注意すること。** 投稿日時点でまだ入荷していない花材を「揃っています」等の現在形で書かない。入荷が月の途中になる場合は「○○ごろから入荷予定」のように時期を明示する。
- **入荷時期説明は「店主の待ちの物語」化する。** 客観的な時期説明（「中旬ごろからの入荷を予定しております」）より、店主の選別期間の物語（「5月はグッと堪えて入れませんでしたが、6月上旬から満を持して登場します」）の方が店主トーンに合う。「○月は意図的に外していた／待っていた」のような時間軸ストーリーで、店主の判断・舞台裏の物語性を込める。マイナス語（萎みやすい／楽しみにくい）は避け、選別・タイミングのこだわりとして表現する。
- **時期が早まる／本格化する場合は期待感を含む語と組み合わせる。** 「中旬ごろから」のような控えめ予告より、「上旬から満を持して」「ようやく」「いよいよ」のような期待感を醸成する語と時期を組み合わせる。
- **2パターン提案時は書き出しのアプローチを変えること。** 同じ花材名・同じ切り口で始めず、片方は季節感から入る・片方は花材から入る等、第1文の視点を意識的に変える。
- **業界用語・造語の難解さをチェックする。** 「抱え咲く」「咲き重なる」のような花業界用語や造語は、一般読者に伝わるか必ず検討する。難解なら平易な比喩（「カップを描くように咲く」「ふっくら重なる」など）に置き換える。
- **格助詞の正確性に注意する。** 動詞の取る格助詞を確認する（×「花たちで手向ける」／○「花束を手向ける」── 「手向ける」は対象を「を」で受ける）。
- **初稿の完成度を引き上げ、TODO往復サイクルを最小化する。** AI初稿 → ユーザーが文章中にTODOタグを埋めて返却 → AI流し込み、という差し戻しは往復コストが高い（数ターン消費する／意図のずれが残る）。これを避けるため、（1）写真確認・テーマ表現・切り口判断・告知配置などの**判断系は事前ステップの[Question]/[Answer]で完結**させる、（2）**過去のカレンダー投稿との被りチェック（メッセージレベル）を初稿提案前に自己実施**する、（3）初稿は「ユーザーが微調整指示するだけで完成形に近い」レベルを目標とする。
