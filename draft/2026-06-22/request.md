# 通常投稿リクエストテンプレート

あなたは、花業界のマーケティングに精通した熟練のWebライターです。
以下のルールに従って、インスタグラムに投稿する花屋の告知文面を **2パターン** 提案してください。
いずれかのステップで私の説明や意見が必要な場合は、[Question]タグを付けて質問ドキュメントを下部に追加し、推奨案を添えて、私が回答を記入するための空の[Answer]タグを作成して人間にボールを回してください。重要な決定を独自に行わないでください。

## 参照ルール

- 執筆ルール：`rules/writing_rules.md`
- 初稿提出前セルフチェック：`rules/self_check.md`
- 投稿文面案：`draft/{{投稿日}}/content.txt`

## 作業の進め方

文面を書き始める前に、以下のステップを踏むこと。

### ステップ0：過去投稿の確認
- `posted/normal_post/` にある過去の確定投稿を読み、文体・構成・トーンを把握してから執筆に入る。

### ステップ1：写真の構成を正確に把握する
- トップ写真に写っている要素（花材、器、配置、数量）を正確に読み取り、[Question]で確認する。
- 器が複数ある場合、それぞれに何が入っているかを個別に把握する。
- 思い込みで花材の組み合わせを決めつけない。

### ステップ2：テーマの表現分析・検討
- いきなり文面を書き出さず、テーマを魅力的に伝えるための**表現やキーワードを分析・検討する**ステップを挟む。
- 以下の観点で検討し、request.mdに[Question]として提示する：
  - テーマを端的に伝えるキーワード候補（例：「二輪挿し」「ペアリング」「2本生け」など）
  - そのキーワードの適切さ（一般的な理解、誤解の可能性、業界での使われ方）
  - キャッチコピーの方向性（詩的・提案型・How to型など）
  - テーマの魅力を伝える切り口（コツ提案、ライフスタイル提案、知識共有など）
  - プロとしての視点、工夫(花選びや、生け方、組み合わせ、色合わせ、質感、ラインなど)

### ステップ3：文面の執筆
- ステップ1・2の確認が取れてから、`rules/writing_rules.md` に従って文面を執筆する。
- **初稿を提示する前に、必ず `rules/self_check.md` の各項目を通すこと。**（写真描写の精度・表現の素朴化・既出メッセージの重複・横串チェック等）

## ファイル運用ルール

- `draft/{{投稿日}}/content.txt` には検討過程（全パターン）をそのまま残す。クリーンアップしない。
- 確定版は `posted/normal_post/{{投稿日}}.txt` に生成する。
- **日付のフォーマットはハイフンつなぎ `YYYY-MM-DD` で統一する。**（例：`2026-03-07.txt`）

## 投稿情報（毎回記入）

- **投稿のテーマ**： アジサイ
- **写真の説明**：
  - トップ（1枚目）：draft/2026-06-22/1000037338.jpg
  - その他：他の2枚のjpg
- **主な花材・グリーン名**：写真から判断してください
- **アピールしたいポイント**：特になし
- **関連する季節行事・イベント**：梅雨

## Question / Answer（初稿執筆前の確認）

### ステップ1：写真の構成確認

[Question 1] 写真1（トップ）のアレンジメントの花材を、以下のように読み取りました。特に確信が薄い★印を確認させてください。
- 中央：ピンク〜藤色のアジサイ（主役）
- くすんだラベンダー／モーブのバラ 2〜3輪
- スモークツリー（白〜グレージュのふわふわ）
- ★淡ピンクのアンスリウム（ハート型）右上 … アンスリウムで合っていますか？
- ★茶系のコーン状のネイティブフラワー（右） … プロテア系でしょうか？品種名があれば。
- ★白い小花 … スターチス／リモニウム系でしょうか？
- ★根元の赤銅色の巻いたリーフ … ニューサイランかコルジリネ（ドラセナ）でしょうか？
（推奨：不確実なものは初稿では「グリーン」「ネイティブフラワー」等の包括語でぼかします）

[Answer 1]
推奨の通り。

[Question 2] 写真2（緑〜青のアジサイのアップ）について。
- これは「アンティークアジサイ／秋色アジサイ」系という理解で合っていますか？特定の品種名はありますか？
- 切り花として店頭にある状態でしょうか、それとも鉢でしょうか？
（推奨：呼称は「アンティークカラーのアジサイ」とし、品種名が出れば追記）

[Answer 2]
切り花として店頭にある。

[Question 3] 写真3（水色の包装の白×グリーンのブーケ）について。
- 花材の読み取り：白ガーベラ／白〜グリーンの小ぶりアジサイ／白い星形の小花（フランネルフラワー？）／グリーンの葉物 … 合っていますか？
- この写真は本文で描写しますか、それとも参考写真（本文非言及）にしますか？
（推奨：今回は「アジサイの色違い」を見せる写真として、本文末尾で軽く言及。フランネルフラワー等の細部は確定したものだけ出す）

[Answer 3]
推奨の通り。

### ステップ2：テーマ表現の確認

[Question 4] 今回の切り口について。直近6/7投稿が「スモークツリー＋アジサイ＋梅雨」で、トップ写真にもスモークツリーが再登場しているため、被りを避けたいです。今回は **アジサイを主役**にし、3枚の写真がいずれも色違いのアジサイ（ピンク紫／アンティークの緑青／白）を含む点を活かして、**「一種なのに色幅が広い・咲き進むと色が移ろう（七変化）」というアジサイの色の物語** を知識共有型で書く方針を推奨します。この方向でよいですか？
（スモークツリーはトップ写真の構成要素として軽く触れる程度に留めます）

[Answer 4]
推奨の通り。

[Question 5] キャッチコピーの候補です（self_checkに従い「季節宣言＋具体物」型を必ず1案含めています）。好みの方向や除外したいものがあれば教えてください。複数案から初稿で2案に絞ります。
- A（季節宣言＋具体物）：梅雨どきの、色とりどりのアジサイ。
- B（七変化を立てる）：ひとつの花の、七つの色。梅雨を彩るアジサイ。
- C（色の移ろい型）：青からアンティークへ。移ろうアジサイの色。
- D（提案型）：白も、青も、くすみ色も。梅雨を楽しむアジサイ選び。
（推奨：A＋C、またはA＋B。Aは素直な宣言型として確保）

[Answer 5]
推奨の通り。また、アジサイとグリーンのかけあわせを推すのもありです。
