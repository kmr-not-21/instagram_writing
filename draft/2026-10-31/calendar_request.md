# カレンダー投稿リクエストテンプレート


あなたは、花業界のマーケティングに精通した熟練のWebライターです。
以下のルールに従って、インスタグラムに投稿する **カレンダー（営業日案内）投稿** の文面を **2パターン** 提案してください。
いずれかのステップで私の説明や意見が必要な場合は、[Question]タグを付けて`draft/2026-10-31/content.txt`ドキュメントを作り、推奨案を添えて、私が回答を記入するための空の[Answer]タグを作成して人間にボールを回してください。重要な決定を独自に行わないでください。

## 参照ルール

- 執筆ルール：`rules/calendar_writing_rules.md`
- 初稿提出前セルフチェック：`rules/self_check.md`
- 投稿文面：`draft/2026-10-31/content.txt`

## 作業の進め方

文面を書き始める前に、以下のステップを踏むこと。

### ステップ0：過去投稿の確認

- `posted/calendar_post/` にある過去の確定投稿を読み、文体・構成・トーンを把握してから執筆に入る。
- **メッセージレベルの重複チェック**：直近のカレンダー投稿（9月・10月）と10月の通常投稿（10-07／10-14／10-21）が伝えた主張・切り口を内部で整理し、既出主張は別の切り口に置き換える。下記「使用禁止・回避リスト」を必ず通すこと。

### ステップ1：投稿情報の正確な把握

- 不定期休業日・営業時間は、カレンダー画像から読み取り依頼者確認済み（下記「投稿情報」参照）。
- 写真は「カレンダー画像＋計20枚」の構成で、**本文では個々の写真には触れない**方針が確定している。写真ごとの品種同定[Question]は不要。
- クリスマスのグリーン・リース資材は**入荷時期をぼかし「順次」で書く**（月初にも月末にも成立させるため）。

### ステップ2：テーマの表現検討

- 11月の軸は **「秋冬の実もの／ネイティブフラワー／クリスマスのグリーン」を並べ、クリスマスは前面に出しすぎない**。
  - 依頼者の言葉：「クリスマスを最前面に出すにはちょっと早いので軽くでいい」。クリスマスグリーンの順次入荷とリースの準備を自然な流れで示しつつ、**晩秋の実もの・ネイティブと同じ重さ**で扱う。冒頭から「クリスマス」で入らない。
  - 名指しは**各カテゴリ1〜2種**に絞る。2パターンで選ぶ品種を変えてよい。
    - 実もの：バラの実／ペッパーベリー／ビバーナムティナス
    - ネイティブ：リューカデンドロン／バーゼリア
    - クリスマスのグリーン：ヒムロ杉／ブルーアイス／コニファー類／グレビレア
  - 表記は「リューカデンドロン」（10-14通常投稿の表記に合わせる。店主メモの「リューカデンドロ」は表記ゆれ）。
- 「ピン留めで月いっぱい表示される」前提のため、**月初にも月末にも古びない書き出し**にする。
  - 月の到来宣言（「11月に入り」）を避ける。
  - その日限りの天気に紐づけない。
  - 晩秋〜初冬への季節の進行で書く。ただし下記「使用禁止リスト」の10月の体感表現と衝突しないよう注意。

### ステップ3：文面の執筆

- ステップ1・2の確認が取れてから、`rules/calendar_writing_rules.md` に従って文面を執筆する。
- **初稿を提示する前に、必ず `rules/self_check.md` の各項目を通すこと。**

## ファイル運用ルール

- `draft/` 内のファイルには検討過程をそのまま残す。クリーンアップしない。
- 確定版は `posted/calendar_post/2026-11.txt` に生成する。**依頼者が「確定」と明示してから書き出すこと。**
- **日付のフォーマットはハイフンつなぎ `YYYY-MM-DD` で統一する。**

## 投稿情報

- **対象月**：2026年11月
- **投稿日**：2026年10月31日(土)　※前月末に投稿してピン留めする運用

### 不定期休業日・営業時間

- **11月7日(土)・12日(木)・26日(木)** はお休み
  - 7日(土)は**綾南マルシェ出店のため**のお休み
- 水曜（4日・11日・18日・25日）は通常どおり13時まで
- 3日(火・文化の日)、23日(月・勤労感謝の日)は**通常営業**（本文では特に触れない）
- 日曜は定休（11月は特別営業なし）
- 通常営業：9:00〜18:00（水曜のみ13:00まで・日曜定休）

### 11月の入荷・見どころ（店主メモより）

| 花材 | 扱い | 備考 |
|---|---|---|
| **秋冬の実もの** | 並列の柱 | バラの実、ペッパーベリー、ビバーナムティナスなど。**10-14通常投稿・10月カレンダーで実もの既出**のため、「丸くてつや」「目が止まる」以外の切り口で |
| **ネイティブフラワー** | 並列の柱 | リューカデンドロン、バーゼリアなど。**ドライフラワーやリースにおすすめ**という角度で（生花として飾ったあとドライにも、等） |
| **クリスマスのグリーン** | 並列の柱（軽め） | ヒムロ杉、ブルーアイス、コニファー類、グレビレア等。**種類豊富に順次入荷**。時期はぼかす |
| **リース資材** | 脇 | クリスマスリースに人気のドライ・木の実・小物。**手づくりする方向けの資材販売**として触れる |

### 告知事項

1. **綾南マルシェ（11月7日(土)）**
   - 会場：綾南幼稚園
   - 時間：10:00〜15:00
   - 出店内容：**リース、ミニブーケ、ドライ雑貨など一点ものの作品を、マルシェプライスで**
   - 依頼者判断で**出店内容・会場・時間まで本文に書く**。ただし営業案内としての可読性を保つため、**2〜3行に収める**（`rules/calendar_writing_rules.md` §3「販促詳細は別投稿へ」との兼ね合い。割引率など価格の具体値は書かない）。
   - 第2段（休業日案内）で「7日はマルシェ出店のためお休み」と案内し、マルシェの中身は直後に続けるか第3段に置くか、2パターンで作り分けてよい。行事名（マルシェ名）を2段にわたって繰り返さないこと（§3「行事名は1回だけ」）。
2. **クリスマスリースのオーダー受付**
   - **早めのご予約を促す**一言を添える。具体的な締切は書かない。
3. **リース資材の販売**
   - 手づくりしたい方向けに、グリーン・ドライ・木の実・小物が揃っていく旨。

### 季節行事

- **いい夫婦の日（11/22）**：触れる場合は**軽く一言**（贈りものの花束の提案程度）。初稿では**入れる案と入れない案**を作り分けて、依頼者に選んでもらう（マルシェ・リース告知と合わせて情報過多にならないかを見るため）。
  - `rules/calendar_writing_rules.md` §3 に沿い、「花を贈る機会」のような販売機会の語で括らない。
- 七五三などその他の行事には触れない。
- 11月は厳寒ではないので、体調への気遣い文は不要。

## 使用禁止・回避リスト（直近との重複回避）

**このリストは初稿執筆時だけでなく、依頼者の手修正版を受け取った後にも必ず再照合すること**（`rules/self_check.md` E-3）。

### 語・フレーズ（そのまま使わない／言い換える）

| 禁止語 | 出典 |
|---|---|
| 朝晩の風がひんやり／日が暮れるのも早く | 10月カレンダー第1文 |
| 朝晩の冷え込みとともに | 10-21 |
| 一気に秋めいていきます／日ごとに秋めいていく | 10月カレンダー／9月カレンダー |
| 深まる秋／秋らしさ満点 | 10-21 |
| ○月の彩りを揃えて、店でお待ちしています | 10月カレンダー締め |
| 絵になりますよ | 10月カレンダー |
| 丸くてつやがある／そこで目が止まります／丸くつややかな実もの | 10-14（実もの） |
| いつもの花瓶に、たっぷりの実ものとグリーンを | 10-14 |
| 個性が光るネイティブフラワー | 8月カレンダー |
| ご用途や込めたい思いに合わせてお作りします | 10-07 |
| ご自宅の秋支度 | 9月カレンダー |

### 主張・切り口（既出のため別角度にする）

- **実もの＝花のあいだのアクセント・色合わせ**（10-14）→ 今回は「秋から冬へ移る季節の実」「リースやドライにも使える」角度で。
- **ハロウィン・カボチャ**（10月カレンダー・10-14）→ 終わった行事なので出さない。
- **前撮り・結婚式・店舗装飾のご相談**（10月カレンダー・10-07）→ 今回は用途提案の主役にしない。

### 季節の常套句への注意

秋テーマの投稿が続いているため、「秋が深まる」「秋めく」だけで第1文を作らない。11月固有の**晩秋から冬への移り変わり**（冬支度、空気の澄み、街が年末へ向かう気配 等）で差をつける。ただし「クリスマス」を第1文に置かない（軸の判断より）。

## 初稿提出前の自己チェック（今回の重点項目）

`rules/self_check.md` の全項目に加え、今回は以下を重点的に見る。

- [ ] 第1文は月末に読んでも古びないか（月の到来宣言なし・その日の天気なし）
- [ ] 上記「使用禁止リスト」の語が本文に入っていないか
- [ ] クリスマスが前面に出すぎていないか（冒頭で触れていない／実もの・ネイティブと同じ重さ）
- [ ] 名指しした花材は各カテゴリ1〜2種に収まっているか
- [ ] 7日(土)のお休みとマルシェ出店が混同されない書き方か（「店はお休み、会場でお待ちしています」が伝わるか）
- [ ] マルシェの告知が2〜3行に収まっているか／マルシェ名を繰り返していないか
- [ ] 「マルシェプライス」以外の価格の具体値を書いていないか
- [ ] リースの「早めのご予約」が押し付けがましくないか
- [ ] いい夫婦の日を入れる案／入れない案を作り分けたか
- [ ] 2パターンで第1文の視点を変えているか（季節感から入る／花材から入る 等）
- [ ] 「ですます」が3文以上連続していないか／句点ごとに改行されているか
- [ ] `(*^^*)` で締めているか／🌱 は1つだけか

## Question/Answer履歴

※以下は2026-10-31のセッション内質疑で確定済み。

[Question 1] 11月の不定期休業日・時間変更・日曜の特別営業は？
[Answer 1] カレンダー画像を添付（`draft/2026-10-31` 内に保存のこと）。

[Question 2] 11月の見どころの軸をどれにしますか？（クリスマス準備を軸／実もの＋ネイティブを軸／3つを均等に）
[Answer 2] 「クリスマス準備を軸」でもよいが、クリスマスを最前面に出すにはちょっと早いので軽くでよい。**クリスマス準備を軸にしつつ、3つを均等に並べる方に寄せる。**

[Question 3] クリスマスリースについて告知することは？
[Answer 3] リースのオーダー受付、資材の販売。リース以外では**マルシェを告知したい**。

[Question 4] 添付写真（カレンダー＋計20枚）は本文で個々の写真に触れない構成でよいか？
[Answer 4] 個々には触れない。

[Question 5] カレンダーの読み取りは正しいか？ ①休み：7日(土)・12日(木)・26日(木) ②水曜(4・11・18・25)は通常どおり13時まで ③3日(火・文化の日)、23日(月・勤労感謝の日)は通常営業 ④日曜の特別営業はなし
[Answer 5] その通り。（祝日の営業は本文では触れない）

[Question 6] 11/7(土)の綾南マルシェはどこまで告知するか？
[Answer 6] 出店内容まで書く。リース、ミニブーケ、ドライ雑貨など一点ものの作品をマルシェプライスで提供。

[Question 7] クリスマスのグリーンやリース資材はいつ頃から店頭に並ぶか？
[Answer 7] 時期はぼかし「順次」で。

[Question 8] 本文で名指しする花材の範囲は？
[Answer 8] 各カテゴリ1〜2種。

[Question 9] 綾南マルシェの会場・時間は本文に書くか？
[Answer 9] 書く。11/7、綾南幼稚園で、10:00〜15:00。

[Question 10] リースのオーダー受付について、締切や受付方法など書きたい条件は？
[Answer 10] 早めのご予約を促す。（具体的な締切はなし）

[Question 11] 11月の行事で触れたいものは？（特になし／七五三／いい夫婦の日）
[Answer 11] 「特になし」と「いい夫婦の日(11/22)」の両方が選択された。→ **いい夫婦の日は軽く一言、入れる案／入れない案を初稿で作り分ける**と解釈。

[Question 12] ハッシュタグの最後の1枠は？
[Answer 12] 初稿で両案提示（`#クリスマスリース`／`#花屋Moja`）。
