# 通常投稿リクエストテンプレート

あなたは、花業界のマーケティングに精通した熟練のWebライターです。
以下のルールに従って、インスタグラムに投稿する花屋の告知文面を **2パターン** 提案してください。
いずれかのステップで私の説明や意見が必要な場合は、[Question]タグを付けて質問ドキュメントを下部に追加し、推奨案を添えて、私が回答を記入するための空の[Answer]タグを作成して人間にボールを回してください。重要な決定を独自に行わないでください。

## 参照ルール

- 執筆ルール：`rules/writing_rules.md`
- 初稿提出前セルフチェック：`rules/self_check.md`
- 投稿文面案：`draft/2026-08-09/content.txt`

## 作業の進め方

文面を書き始める前に、以下のステップを踏むこと。

### ステップ0：過去投稿の確認
- `posted/normal_post/` にある過去の確定投稿を読み、文体・構成・トーンを把握してから執筆に入る。

### ステップ1：写真の構成を正確に把握する
- トップ写真に写っている要素（花材、器、配置、数量）を正確に読み取り、[Question]で確認する。
- 器が複数ある場合、それぞれに何が入っているかを個別に把握する。
- 思い込みで花材の組み合わせを決めつけない。

### ステップ2：テーマの表現分析・検討
- いきなり文面を書き出さず、テーマを魅力的に伝えるための**表現やキーワードを分析・検討する**ステップを挟む。

### ステップ3：文面の執筆
- ステップ1・2の確認が取れてから、`rules/writing_rules.md` に従って文面を執筆する。
- **初稿を提示する前に、必ず `rules/self_check.md` の各項目を通すこと。**（写真描写の精度・表現の素朴化・既出メッセージの重複・横串チェック等）

## ファイル運用ルール

- `draft/2026-08-09/content.txt` には検討過程（全パターン）をそのまま残す。クリーンアップしない。
- 確定版は `posted/normal_post/2026-08-09.txt` に生成する。
- **日付のフォーマットはハイフンつなぎ `YYYY-MM-DD` で統一する。**

## 確定事項（壁打ち済み）

### 1. 用途の書き方

1枚目は四十九日のご依頼品だが、本文では **「お供えにとご依頼いただいたもの」とぼかす**。四十九日と明記しない（弔事の場面を限定せず、お盆・ギフト用途への広がりを残すため）。

`rules/self_check.md` の弔事ルールを厳守すること：
- 店主が故人やお客様の関係を**推測する言い回しを使わない**（「よほど〜だったのだろう」等）
- 過去形（「〜だった」）で関係を語らない
- 店主は「受け取る側・お気持ちに寄り添う側」に立場を引き、**お客様の選択そのものへの敬意**で締める

### 2. 2パターンの軸の棲み分け

| | パターンA | パターンB |
|---|---|---|
| 軸 | **草花で仕立てる供花** | **くすみ色でまとめる供花** |
| 第2段 | 1枚目の草花寄せの構成を描写 | 1枚目を色の観点から描写 |
| 第3段 | 草花寄せの効かせ方（[Answer 4] の (a)＋(c)：庭の一角のような佇まい／面をつくらず線と点で組むので大きく仕立てても重たくならない） | くすみ色の選び方。モーブのバラ、くすみピンク、黒紫の実。白と黒の定番とは別の選択肢としての提案 |
| 書き出し | 花材・仕立てから入る | 季節・色から入る |

`rules/writing_rules.md`「2パターン提案時は書き出しのアプローチを変えること」に従い、第1文の視点を意識的に変える。

**パターンBの重要な制約**：[Answer 3] のとおり **秋色アジサイは8/9時点で店頭にない**。したがって、
- 「秋色アジサイ」を**商品として名指しした訴求はしない**（「出はじめました」「並んでいます」等は不可）
- 写真1・3に写っているアジサイは、写真の描写として「**くすみ色のアジサイ**」程度に留める
- Bの軸は特定花材ではなく、**色の選び方そのもの**に置く（バラ・草花系は在庫あり）

### 3. 写真の扱い

- 1枚目：必須描写
- 2枚目：**描写する**。白×グリーンの束として、トップと同じ草花寄せの文脈でつなぐ
- 3枚目：**本文で一切言及しない**（参考添付のみ）

### 4. 告知の組み込み

**「お盆のお花は15日(土)までに」を本文（第4段落）に組み込む。**
8/16(日)〜23(日)が夏季休業のため、お盆のご相談は15日(土)までとなる。来店動機として自然に織り込むこと。事務的な連絡調ではなく、店主の語り口で。

### 5. ハッシュタグ

**供花軸**とする（[Answer 5] = 案b）。確定：

`#藤沢花屋` `#湘南花屋` `#お盆の花` `#お供えアレンジ` `#草花のアレンジ`

### 6. キャッチコピー

初稿で5〜6案を出して比較する。[Answer 6] より **色から入る型（c）と 季節宣言＋具体物型（a）を優先**。
ただし案cの原文「くすみゆく夏の色。お盆に添える、秋色のアジサイ。」は**秋色アジサイを名指ししているため使用不可**（在庫なし）。「くすみ色」「アンティークカラー」など、色そのものを指す語に置き換えて再構成すること。
`rules/self_check.md` B-1 に従い、「季節宣言＋写っているものの直訳」型を必ず1案入れる。

### 7. 在庫の書き分け（[Answer 3]）

| 花材 | 8/9時点 | 本文での扱い |
|---|---|---|
| 秋色アジサイ | **なし** | 商品訴求しない。写真描写のみ、「くすみ色のアジサイ」に留める |
| 草花系（細い茎の小花、穂もの、実もの等） | あり | 現在形で書いてよい。パターンAの来店動機の核 |
| 供花のご相談・オーダー | 受付可 | 15日(土)までの相談を促してよい |

**チェック対象は直近1ヶ月（7/9以降）の投稿に限る。** `rules/writing_rules.md`「直近1ヶ月の投稿とメッセージ・切り口を重複させない」のとおり。該当するのは以下の2本のみ。それ以前の投稿（5/4のお供え花束、6/7のスモークツリー、6/22のアジサイ等）はメッセージ重複の制約対象外とする。

- 「夏の束は、**使う色を絞るほど涼しく見えます**。白や淡い色に、あとは緑だけ。」
