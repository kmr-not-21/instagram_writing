# 通常投稿リクエストテンプレート

あなたは、花業界のマーケティングに精通した熟練のWebライターです。
以下のルールに従って、インスタグラムに投稿する花屋の告知文面を **2パターン** 提案してください。
いずれかのステップで私の説明や意見が必要な場合は、[Question]タグを付けて質問ドキュメントを下部に追加し、推奨案を添えて、私が回答を記入するための空の[Answer]タグを作成して人間にボールを回してください。重要な決定を独自に行わないでください。

## 参照ルール

- 執筆ルール：`rules/writing_rules.md`
- 初稿提出前セルフチェック：`rules/self_check.md`
- 投稿文面案：`draft/2026-09-06/content.txt`

## 作業の進め方

文面を書き始める前に、以下のステップを踏むこと。

### ステップ0：過去投稿の確認
- `posted/normal_post/` にある過去の確定投稿を読み、文体・構成・トーンを把握してから執筆に入る。

### ステップ1：写真の構成を正確に把握する
- 済。読み取り結果はセッション内の質疑で確認済み（下記「確定事項」参照）。

### ステップ1.5：テーマ候補の提示（壁打ち）
- 済。3案の壁打ちから「A＋Bミックス」に確定（下記「確定事項」参照）。

### ステップ2：テーマの表現分析・検討
- いきなり文面を書き出さず、テーマを魅力的に伝えるための表現やキーワードを分析・検討するステップを挟む。

### ステップ3：文面の執筆
- `rules/writing_rules.md` に従って文面を執筆する。
- **初稿を提示する前に、必ず `rules/self_check.md` の各項目を通すこと。**

## ファイル運用ルール

- `draft/2026-09-06/content.txt` には検討過程（全パターン）をそのまま残す。クリーンアップしない。
- 確定版は `posted/normal_post/2026-09-06.txt` に生成する。

## 投稿情報

- **投稿のテーマ**：**A＋Bミックス「初秋の空気を壁に飾るドライリース ×（第2段で）素材のかけあわせ」** — 初秋の季節感を軸にしつつ、第2段でスターチスの小花・実もの・アジサイなど「かけあわせ」の面白さをクローズアップする構成
- **写真の説明**（全10枚予定。文面はこの3枚を軸に書いてOK。残りは同系統のドライリース・ドライ花材の雰囲気カット）：
  - トップ（1枚目）：`1000037803.jpg` — ホワイト×グリーン×淡ピンクのドライリース。白い小花（宿根スターチス）を敷き詰め、くすみピンクのハイブリッドスターチス、グリーンのアジサイ"妖精の羽音"、ニゲラの実、ナンキンハゼの白い実、丸葉のユーカリ、数種のグリーン。ガラスケースの上で撮影
  - 2枚目：`1000037805.jpg` — リース4点の集合写真。ピンク系（プリザーブドのバラ・アジサイ＋クラスペディア）、ホワイト×ベージュ系（白バラ・白アジサイ）、トップと同じホワイトグリーン系、マゼンタ系（千日紅＋ドライオレンジ＋スターチス）。色幅の豊かさが伝わる1枚
  - 3枚目：`1000038176.jpg` — 店内のドライ花材コーナー。ドライのアジサイ（深紫・グリーン・アンティークレッド）、芍薬（ピンク）などが一本ずつ並ぶ様子
- **主な花材・グリーン名**：宿根スターチス（白い小花）、ハイブリッドスターチス（くすみピンク）、アジサイ"妖精の羽音"（グリーン）、ナンキンハゼ（白い実）、ニゲラの実、ユーカリ。**この中で特徴的なものをよしなに選んで使う**（全部を列挙しない）
- **アピールしたいポイント**：
  - すべて手仕事の一点もの（一本売りのドライ花材も含め、店で手仕事で作っている）
  - 初秋の新作が**少しずつ並び始めた**タイミング（「充実」「勢揃い」のような盛った表現にしない）
  - **オーダーも受けられる**ことを勧めたい（一部は売約・オーダー品のため、「同じ雰囲気でお作りできます」の文脈）
- **関連する季節行事・イベント**：敬老の日（9/21）に**軽く**触れる（ドライ＝長く飾れる、と贈りものの相性の範囲で一文程度）

## 確定事項（壁打ち済み・2026-09-06セッション質疑）

### 1. テーマ：A＋Bミックス

- A案「初秋の季節軸」を主軸に、B案「素材のかけあわせ軸」（実もの×小花×グリーンの質感）を第2段で展開する構成。
- C案（店の風景軸）は主軸にはしないが、3枚目のドライ花材コーナーには**最終段で軽く触れる**（来店誘導）。その際「ドライ花材はすべて手仕事で作っている」ことにも触れる。

### 2. トップ写真の花材（確認済み）

- 白い小花 → **宿根スターチス**
- くすみピンクの花 → **ハイブリッドスターチス**
- グリーンの花 → **アジサイ"妖精の羽音"**
- 白い実もの → **ナンキンハゼ**
- ニゲラの実、ユーカリ、その他グリーンの読み取りは概ね合っている。
- 品種名・花材名は「特徴的なものをよしなに」選んで使う。全列挙はしない。

### 3. リースの販売状況

- 4点のうち**一部は売約・オーダー品**。「全部店頭に並んでいます」とは書かない。
- 「店頭に並びはじめています」＋「お好みの色や雰囲気でのオーダーもできます」の両輪で書く。**オーダーの後押しは依頼者の意向**。

### 4. 行事言及

- 敬老の日（9/21）に軽く触れる（一文程度）。しっかり推しにはしない。
- ※9月カレンダー投稿で「20日(日)はお彼岸・敬老の日にあわせて営業」を告知済み。営業日情報はこの投稿では繰り返さなくてよい。

### 5. 写真の扱い

- 全10枚予定だが、文面は上記3枚の内容を踏まえて書けばよい（残り約7枚は同系統の雰囲気カット）。

## AIによる事前チェックメモ（過去投稿とのメッセージ被り）

重複チェック対象：2026-02-15（ドライ＆プリザーブドリース）、2026-08-23（一足早い秋の花）、2026-09カレンダー投稿。

- **2026-02-15 リース投稿の既出メッセージ**：「長く飾れる・色褪せない」／「一つ一つ手仕事で製作」／「リースといえば秋冬のイメージ」／「贈りものに人気」→ **「長く楽しめる」「手仕事」は言い回しを変えて再登場させる**（例：手仕事→「ひとつずつ束ねて／挿して」など工程の描写に落とす）。「リース＝秋冬」の知識ネタは既出のため使わない。
- **2026-08-23 の既出メッセージ**：「花屋の店先は、季節が少しだけ早く進みます」「一足早い秋」→ **"季節の先取り"ロジックの同じ言い回しを避ける**。今回は「壁・部屋に秋の空気を飾る」方向（場所の視点）で差別化する。
- **2026-09 カレンダー投稿の既出メッセージ**：「ドライ作品を少しずつ並べていきます」「グラス類は長く楽しめる」「敬老の日」→ カレンダーの"予告"をこの投稿で"回収"する関係。**「少しずつ並べていきます」と同じ文言の繰り返しは避け、「並びはじめました」と現在形で書く**。「長く楽しめる」の press はカレンダーで使ったばかりなので敬老の日の一文の中に留める。
